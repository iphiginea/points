# Points

A guided practice app that turns an interactive body map into the starting point for a focused, calming session.

**Live app:** https://iphiginea.github.io/points/

## About

Points begins with the body instead of a menu. Choose a point on the interactive map, name what you are carrying that day, and follow a guided session built around attention, breath, pacing, and ritual.

The project explores whether some of the focus and intentionality associated with acupuncture can become an at-home experience without needles.

## Features

- Interactive body-map entry point
- Point-specific guided sessions
- Timed breathing and pacing cues
- Session copy designed around feelings and focus
- Installable browser experience

## Stack

- JavaScript
- Web audio and timed interaction
- Progressive Web App features
- GitHub Pages
